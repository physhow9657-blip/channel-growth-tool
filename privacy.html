Privacy Policy · 개인정보처리방침

Last updated: 2026-11-26

Data accessed

With the user's consent, the tool uses YouTube API Services with read-only scopes (youtube.readonly, yt-analytics.readonly) to read channel information, video statistics and analytics reports of the user's own channels.

Use, storage, sharing

Data is used only to produce performance reports for the channel owner. Access tokens and report data are stored only on the owner's own computer. The tool has no server. Data is not sold, is not used for advertising, and is not transferred to third parties, except that the owner may process reports with software assistants and messaging services chosen by the owner to deliver them to the owner.

Deletion and revocation

Delete the local token and report files to remove stored data. Access can be revoked at any time at Google Account permissions.

Policies

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
